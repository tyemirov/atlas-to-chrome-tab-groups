# Screenshots and visual references

`01-wrong-folder-selected.png` is a real Chrome error screenshot captured during installation. It illustrates the harmless error caused by choosing the package root instead of the `extension/` subfolder.

`02-select-extension-folder.svg` and `03-success-report.svg` are privacy-safe visual references. They intentionally use generic names and counts rather than a real person’s tab titles, URLs, or group names, so this kit can be reused or shared privately without exposing a browser workspace.
